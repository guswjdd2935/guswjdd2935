### 2. Transformer 기반 분류 모델 실험

Transformer backbone에 classification head를 붙여 구조화된 라벨을 예측하는 실험입니다.

| 항목         | 내용                                           |
| ---------- | -------------------------------------------- |
| Task       | 계층적 문서 분류                                    |
| Method     | Pretrained Transformer fine-tuning           |
| Approach   | Prompt generation이 아닌 classification head 방식 |
| Focus      | 모델 구조 비교, 학습 방식 비교, 성능 평가                    |
| Repository | [View Project](링크넣기)                         |
| Status     | 진행 중 / 완료                                    |

### 3. AI 모델 비교 및 평가 실험

| Repository    | [View Project](링크넣기)      |
